2. QA-004 (Money) Rule Determination & Money Chain Analysis

The Confirmed Core Rule:
"Doctor share comes from the snapshot on the paid bill, attributed to the session where the patient was actually seen."

The Complete Bill → Token → Session → Fee Snapshot Chain:

  1. Initial Booking in Session 1 (Dr. Old): Patient Sunil pays Bill #101. Total collected is Rs. 2,000 (Dr. Old fee: Rs. 1,500 + Clinic fee: Rs. 500). Fee snapshot records doctor_fee = 150000.
  2. Token Move to Session 2 (Dr. New): Patient Sunil is moved to Dr. New's session (where standard fee is Rs. 2,500). The token moves and the paid bill is re-linked to Dr. New, but no differential cash was collected from the patient. The paid bill snapshot remains immutable at Rs. 1,500.
  3. Settlement Calculation: The payout engine inspects the paid bill and attributes the recorded doctor fee snapshot (Rs. 1,500) to Dr. New for the consultation performed in Session 2.

Code vs Test Expectation:

  • Value Code Produces: 1500 LKR
  • Value Test Expects: 2500 LKR
  • Which one is right per rule? The CODE is right. If the clinic paid Dr. New Rs. 2,500, the clinic would incur an uncollected deficit of Rs. 1,000 because only Rs. 2,000 was collected from the patient. The test assertion must be updated to 1,500.
